# @incidentflow/contracts

Runtime Zod schemas and inferred TypeScript types shared by Fastify and the
Next.js backend-for-frontend. Includes the coded-error envelope, identity/session,
incident, service and realtime contracts, plus the public demo definition.
Migrate remaining response boundaries incrementally when their APIs change.

Read [ADR 0002](../../docs/decisions/0002-native-fetch-and-api-contracts.md) when
changing contract ownership or runtime validation, and
[architecture](../../docs/architecture.md) for related application boundaries.
